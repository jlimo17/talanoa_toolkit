# Talanoa Toolkit

Co-designing wellbeing, together.

Talanoa Toolkit is an interactive prototype for a participatory design platform that lets organisations build wellbeing programs *with* their communities rather than *for* them — walking through five stages: Session Builder, Capture, Synthesis, Blueprint, and Closing the Loop.

This repo contains a working demo built in React.

## Running it locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

## Building for deployment

```bash
npm run build
```

Outputs a static site to `dist/`, deployable to GitHub Pages, Netlify, Vercel, or any static host.

## Status

Early-stage prototype, not production software. The wellbeing frameworks referenced (Fonofale, Te Whare Tapa Whā) are simplified for demonstration purposes and should be reviewed with cultural advisors before any real-world use.
